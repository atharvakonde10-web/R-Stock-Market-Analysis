8. Calculate Daily Price Change

my_stocks <- my_stocks %>%
  arrange(stock_symbol, date) %>%
  group_by(stock_symbol) %>%
  mutate(
    daily_change = stock_price_close -
                   lag(stock_price_close)
  ) %>%
  ungroup()

The daily change is calculated by subtracting the previous day’s closing price from the current day’s closing price.

The lag() function is used to obtain the previous day’s closing price.

highest_gain <- my_stocks %>%

16. Average Closing Price of Stocks

average_close <- my_stocks %>%
  group_by(stock_symbol) %>%
  summarise(
    average_closing_price =
      mean(stock_price_close, na.rm = TRUE)
  ) %>%
  arrange(desc(average_closing_price))
